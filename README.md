# wowfish

给 WoW Forever 用的一套个人工具：听声自动钓鱼、自动分解、拍卖行绿装捡漏（扫货 → 买入 → 上架）、买卖记录。
由两部分组成：

- **游戏内插件 ForeverQuant**（`/fq`）：面板、拍卖行扫描、估值、买卖记录。所有功能都在这里开关。
- **电脑端程序**（`agent.sh`）：一直开着。它看游戏窗口左上角的几个小色块（插件画的信号），替你按键；顺带跑行情分析。

> **风险自负。** 自动按键违反暴雪的用户协议，账号可能被封。这套东西没有做、也不会做任何躲避检测的处理。
> 它只在游戏窗口处于前台时发按键，只操作游戏内金币，不涉及现实货币交易。

## 安装（Linux / macOS）

```bash
curl -fsSL https://raw.githubusercontent.com/zenpl/wowfish/main/install.sh | bash
```

或者自己 clone 后运行 `./install.sh`。脚本会：建虚拟环境装依赖 → 找到游戏的 `Interface/AddOns` 并把插件链接进去 → 打印游戏内还要做的几步。
找不到游戏目录时手动指定：

```bash
WOW_ADDONS="/…/World of Warcraft/_forever_/Interface/AddOns" ./install.sh
```

需要 Python 3.11 以上。然后启动电脑端程序并一直开着：

```bash
~/wowfish/agent.sh
```

### 两个系统各自的前提

| | Linux | macOS |
|---|---|---|
| 状态 | 日常在用 | **移植版，没有在真机上测过** |
| 桌面 | X11 会话（Wayland 不行） | — |
| 听声钓鱼 | PipeWire（`pw-record`） | BlackHole 虚拟声卡 + 多输出设备，见 `mac/README.md` |
| 权限 | — | 终端要有：辅助功能、屏幕录制、麦克风 |
| 开机自启 | 可选：`./install-service.sh` | 没做 |

macOS 上如果信号认不出来（面板一直显示"电脑端程序：没连上"），多半是屏幕录制权限没给，或显示器的色彩描述文件把纯色改了；请带上现象提 issue。

### 游戏内一次性设置

1. 重新登录角色（新插件要重登才加载），输入 `/fq` 打开面板。
2. 聊天框输入 `/console SoftTargetInteract 3`；按键设置里把「与目标互动」绑到 `F10`。
3. 钓鱼技能放到按 `0` 触发的动作条格子；打开自动拾取；游戏用窗口模式。
4. 插件自己会占用 F5–F9、F11、F12 里空闲的键（分解宏和"动作键"），不要把它们绑给别的。
5. 打开拍卖行点「扫描整个拍卖行」，扫完 `/reload` 一次；电脑端会自动出第一份分析，再 `/reload` 就能看到。

面板标题显示"电脑端程序：已连上"才说明两边通了。

## 面板怎么看

界面上三种控件，位置和样子固定：**页签**（左上，纯文字）决定看哪张表；**操作**（右上，红色按钮）做一次；**开关**（右下，方框打勾）一直开着或关着。

- **蹲点钓鱼**：开「自动钓鱼」后电脑端听水花声收竿（期间自动关掉音乐和环境音，停了恢复）。面板统计这片水域实际钓到什么、每小时值多少。每行末尾的按钮可以把灰/白品质的鱼标成"会扔"，背包快满时自动销毁（不可恢复，先拿一种确定不要的试）。背包满、死亡、掉线会自动停。
- **分解套利**：「今天划算的」列出买来分解有得赚的绿装；「我常分解的」是固定反复买的货，带一键自动分解。看两个数：按现价每件赚多少、止买线在哪。有些物品游戏不让分解，标"先试一件"的没实测过。
- **倒卖套利**：
  - 「绿装捡漏」：随机后缀绿装里被标错价的。星级 = 这件东西好不好，差价 = 目标价是现价的几倍，「建议」由两者一起定；还会去查同款别人挂多少来印证。行首小按钮左键标「要」（立刻去买）、右键标「不要」，标注会留下校正记录。
  - 「配方转卖」：商人卖、拍卖行能加价卖的配方，带商人位置导航。
  - 「买卖记录」：每笔买入、上架、卖出、流拍，净赚和卖掉用了多久。
  - 「各时段价格」：大宗货一天里哪个时段便宜、哪个时段贵。
  - 三个开关按流程排：**自动扫货**（高概率池几秒一轮 + 每分钟一次全量）→ **自动买入**（只买「建议」是"买"的）→ **自动上架**（先查同款，贴着同款最便宜的挂）。

## 电脑端命令（可选）

电脑端程序会自己跑分析，下面这些只在想手动看的时候用：

```bash
cd ~/wowfish/forever-quant
../.venv/bin/python -m quant gear      # 用最近一次游戏内扫描重算，写回插件
../.venv/bin/python -m quant tod       # 大宗货各时段价格
../.venv/bin/python -m quant marks     # 游戏里标的「要 / 不要」和模型判断的对照
../.venv/bin/python -m quant watch     # 常分解的货的经济账
```

估值规则都在 `forever-quant/config.toml`（各职业要什么属性、各种阈值）。本机设置写在 `forever-quant/local.toml`，不进仓库。
配方商人的位置读的是本机安装的 Questie 插件数据，没装 Questie 就没有导航。行情数据来自 [AHledger](https://ahledger.com) 的公开接口和你自己在游戏里的扫描。

## 已知限制

- 估值规则是按一个服务器（部落、PvE）的经验调的，换服务器要先自己扫几轮、看几天再信它。
- 自动买入花的是真金币：单笔核对实时价格，总花费不超过手头金币的八成，但模型会错。先用「标注」攒些校正记录再放开。
- 游戏内很多路径只在 Linux 上实际用过；macOS 版电脑端程序整体未实测。
- 沿岸走动（`roam.py`）是没做完的实验，不要用。
